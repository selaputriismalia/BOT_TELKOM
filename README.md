## 📌 Ringkasan Projek
Bot Telegram automasi yang dikembangkan selama masa magang di **PT Telkom Indonesia**. Bot ini dibuat untuk mengatasi lambatnya proses validasi data jaringan secara manual dengan mengintegrasikan skrip Python, Google Cloud Sheets/Drive API, dan Telegram Bot API. Sistem ini memudahkan teknisi dan tim lapangan untuk mengakses serta memvalidasi data infrastruktur jaringan FTTH/FTTX secara instan.

## 🚀 Fitur Utama
- ⚡ **Akses Data Instan:** Pencarian dan pengambilan data detail infrastruktur jaringan (ODP, STO, ketersediaan port) dalam hitungan detik melalui perintah Telegram.
- 🔄 **Integrasi Google API Otomatis:** Sinkronisasi log data jaringan dan catatan spreadsheet secara *real-time*.
- 🎯 **Akurasi & Validasi Data:** Meminimalisir potensi *human error* saat pengecekan dan input data lapangan secara manual.

## 🛠️ Tech Stack & Library
- **Bahasa Pemrograman:** Python 3.x
- **API & Layanan Cloud:** Telegram Bot API, Google Sheets API, Google Drive API
- **Library Python:** `python-telegram-bot`, `gspread`, `oauth2client`, `pandas`

## 📊 Dampak Bisnis & Hasil
- Mempercepat waktu pengecekan data jaringan untuk operasional tim lapangan hingga **~60%**.
- Meningkatkan akurasi data serta efisiensi alur kerja antara teknisi lapangan dan tim *back-office*.
